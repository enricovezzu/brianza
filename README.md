# Brianza

Gioco 3D di corse, da giocare nel browser.

## [▶ Gioca ora](https://enricovezzu.github.io/brianza/)

`https://enricovezzu.github.io/brianza/`

### Sul telefono (iPhone)
1. Apri il link in **Safari**.
2. Tocca **Condividi**, poi **Aggiungi alla schermata Home**.
3. Si apre a schermo intero, come un'app, e funziona anche senza rete.

### Comandi
- **Spazio** o pulsante **CORRI**: corri (più tocchi veloci, più vai veloce).
- **A / D** o **← / →**: sterza.
- **P** o **Esc**: pausa.

Le scelte e gli yuzu restano salvati sul tuo dispositivo.
